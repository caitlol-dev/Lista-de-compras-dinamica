Minha Wishlist Interativa

Uma aplicação web leve, moderna e responsiva para gerenciamento de lista de desejos (wishlist). Permite organizar compras futuras por prioridade, monitorar o valor total estimado, fazer upload ou vincular fotos e redirecionar diretamente para as lojas de sua preferência.

Funcionalidades

Cadastro de Itens: Adicione itens com nome, preço estimado, prioridade, link direto da loja e imagem.
Suporte a Imagens: Faça upload de imagens locais (armazenadas em Base64) ou cole a URL de uma foto da web.
Níveis de Prioridade: Classificação visual simples por cores:
    🔴 Alta
    🟡 Média
    🟢 Baixa
Links Diretos:
  - Botão de Link do Produto para ir direto à loja cadastrada.
  - Botão de Google Shopping para pesquisar o menor preço automaticamente com um clique.
Modal de Edição: Altere preço, prioridade, link e imagem de qualquer item salvo a qualquer momento.
Resumo Financeiro: Cálculo automático do valor total estimado dos itens não comprados e contagem de itens.
Persistência Local: Todos os dados ficam salvos no navegador do usuário via `localStorage`.
